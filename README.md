# 小布的记账本 · qianbao

面向大学生日常使用的本地记账 PWA，适配 iPhone，支持离线记账。

## 3.0 已完成 · 离线缓存 v21

3.0 在 2.9 的十项功能之外，加入缓存优先启动、离线文件修复与真实下载进度（50个文件）。

在 2.8 基础上加入以下功能，保留“小布的记账本”名称、本地存储键 `lanyu-ledger-v1` 和 version 1 JSON。无后端、无账号、不上传数据，所有功能离线可用。

- 晚上 9 点提醒：默认开启，21:00 后打开或每分钟检查，当天无任何账单时在首页提醒。点击提醒或关闭后当天不再出现；设置可关闭。应用关闭时不能推送手机通知。
- 月总结 → 日历：显示每天支出深浅及绿色收入，支持上/下月；点日期查看当天记录，可复用编辑、删除。
- 收支记录：金额下限/上限与关键词、类型、分类、日期组合，包含边界；负数、非法输入忽略，下限大于上限时忽略整个金额范围并提示。
- 收支记录 → 保存当前筛选：输入最多 16 字名称，标签可套用或删除；重名询问是否覆盖，删除标签不删除账单。
- 月度文字小结：收入、支出、结余、最大支出大分类及占比、与上月金额和比例对比。无账单、上月无支出单独说明；并列按分类排列顺序取第一个。
- 月总结 → 年度总览：切换年份查看 12 个月收支柱与年汇总，月均按全年 12 个月计算（包含零收支月份）。
- 设置 → 攒钱目标：名称最多 20 字，目标金额、可选日期及手动已存金额；显示进度、剩余金额、天数，到期日及之后显示“已到期”，超额满格显示“已达成”。可编辑、删除，不影响账单。
- 设置 → 借出借入：姓名最多 16 字，独立记录方向、金额、日期、备注、未还/已还；按日期倒序汇总未还金额。标记已还使用当天日期，可在编辑中改还款日期，也可改回未还。往来不计余额、收支或图表，如需计入收支请另记正常账单。
- 固定支出：设置同时显示今天、明天待记数量，模板标注“明天待记”；提前一天不能记账，到期当天仍需确认。短月按月末，每周按星期，今天已记的模板不提醒。
- 月预算 → 提醒比例：默认 80%，可输入 50–100 的整数，箭头步进 5，越界夹到范围内，点“保存提醒比例”。总预算与分类预算共用此比例，超过额度仍显示超预算。

JSON 新增可选 `savedFilters`、`goals`、`loans`、`eveningReminder` 和 `budgets.threshold`，保留原账单、分类、模板及其他字段。旧备份恢复后常用筛选/目标/往来为空，晚间提醒开启、比例 80%。原有模板、CSV、JSON 备份提醒与 PIN 功能保留；PIN 只遮挡界面，不加密存储或备份。完整方法见 [使用说明.md](使用说明.md)。

## 功能

- 支出、收入、总余额与月度结余。
- 自定义大分类和细分类，卡通透明图标；支持从相册上传自己的分类图片。
- 大小分类左右滑动，收支记录与统计列表上下滑动。
- 账单新增、编辑、删除与 JSON 备份恢复。
- 苹果白默认主题，可手动切换其他主题，不跟随系统。
- Service Worker 离线缓存；账单保存在设备浏览器本地存储。

## 本地启动

安装 Python 3.10 或更高版本，然后运行：

```sh
python -m pip install -r requirements.txt
python serve.py
```

Windows 也可双击 `启动局域网.cmd`。

手机与电脑连接同一 Wi-Fi，根据终端显示的地址打开安装页。首次在 iPhone 上安装并信任本机生成的证书后，用 Safari 打开 HTTPS 记账页面，通过分享菜单添加到主屏幕。设置显示“离线已就绪”后可离线使用。

证书和私钥在运行时生成于 `.local/`，不包含在仓库中。每台电脑单独生成自己的证书。

## 项目结构

- `public/`：HTML、CSS、JavaScript、PWA 清单与图标。
- `serve.py`：本地 HTTPS 服务与 iPhone 安装引导。
- `使用说明.md`：完整使用方法与版本说明。

保持原 IP 与端口更新应用，以继续使用同一来源中的本地账单。请定期在设置中导出备份；GitHub 仓库保存的是程序代码，不包含手机上的账单。

## 验证范围

`tests/batch3.cjs` 覆盖 2.9 十项功能、时间和统计边界、目标及往来编辑/删除、JSON 新旧备份往返、旧账单保持、三种视口与 JS 运行错误。`tests/batch2.cjs` 保留 2.8 回归，`tests/integration3.cjs` 覆盖缓存优先启动、离线修复与 50 项缓存进度。测试先请求拦截加载，等待 v21 缓存后取消拦截并断网重载，后续操作均离线进行。

需要 Node.js、Playwright 和 Chromium。在一个终端运行 `python3 -m http.server 8765 --bind 127.0.0.1 --directory public`，另一个运行 `node tests/batch3.cjs` 和 `node tests/integration3.cjs`；可通过 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`、`CHROMIUM_ARGS`（JSON 数组）指定依赖。

iPhone Safari 真机、刘海安全区、系统后台生命周期、Excel 桌面软件实际打开和已安装 v20 应用真实升级需在相应设备确认。自动测试使用独立账本，21:00 检查使用浏览器模拟本地时间。
