# 小布的记账本 · qianbao

面向大学生日常使用的本地记账 PWA，适配 iPhone，支持离线记账。

当前版本 **3.0**：合并预算、组合筛选、图表、周期模板、CSV 和 PIN 锁，并加入缓存优先启动、离线文件修复与真实下载进度（49个文件）。

## 2.8 已完成

两批功能现已完成：月预算、搜索与组合筛选、分类支出和近六个月图表，以及固定支出模板、CSV 导出、备份提醒和可选 PIN 开屏锁。离线缓存同步升级到 v18，不改写已有账单，不包含用户电脑上尚未上传的部署测试。

- 设置 → 固定支出：添加名称、金额、大/细分类、每月扣款日或每周星期。当天在设置提醒，点“记一笔”修改金额、备注后保存；不会自动生成或扣款。每月 29–31 日遇短月按月末提醒，今天已记的模板不再提醒。
- 设置 → 数据备份 → 导出 CSV：选择全部、本月或收支记录页当前搜索/筛选结果。文件为 UTF-8 BOM，字段依次为日期、类型、大分类、细分类、金额、备注，文件名如 `lanyu-ledger-2026-11-10.csv`。用户文本中可能被 Excel 识别为公式的首字符会加单引号保护。
- 设置 → 数据备份：尚未导出或距上次 JSON 导出超过 7 天显示提醒，点击直接导出。CSV 不代替 JSON 恢复备份；下载后请确认文件已保存。
- 设置 → 数据安全 → 开屏锁：默认关闭，输入两次 4 位数字 PIN 开启；打开应用及从后台切回需解锁，错 5 次锁 1 分钟，重开仍保留倒计时。解锁后可关闭或更换 PIN。忘记 PIN 可在锁屏页经两次确认清除本机账本及恢复前副本；先确认已有备份。

JSON 沿用 `format: lanyu-ledger`、`version: 1`，新增可选 `templates`、`lock`（盐和校验值，无明文 PIN）、`lastBackupAt`，以及第一批 `budgets`。模板记账增加可选来源标记，原有账单字段不变。旧备份缺字段时恢复为空模板、无预算、关闭 PIN；含 PIN 的新备份恢复后需用对应 PIN 解锁。所有功能本机离线运行，无后端、无账号、不上传。开屏锁遮挡界面，不加密账单或 JSON，请妥善保存备份。

## 功能

- 支出、收入、总余额与月度结余。
- 自定义大分类和细分类，卡通透明图标；支持从相册上传自己的分类图片。
- 大小分类左右滑动，收支记录与统计列表上下滑动。
- 账单新增、编辑、删除与 JSON 备份恢复。
- 苹果白默认主题，可手动切换其他主题，不跟随系统。
- Service Worker 离线缓存；账单保存在设备浏览器本地存储。

## 本地启动

安装 Python 3.10 或更高版本，然后运行：

```sh
python -m pip install -r requirements.txt
python serve.py
```

Windows 也可双击 `启动局域网.cmd`。

手机与电脑连接同一 Wi-Fi，根据终端显示的地址打开安装页。首次在 iPhone 上安装并信任本机生成的证书后，用 Safari 打开 HTTPS 记账页面，通过分享菜单添加到主屏幕。设置显示“离线已就绪”后可离线使用。

证书和私钥在运行时生成于 `.local/`，不包含在仓库中。每台电脑单独生成自己的证书。

## 项目结构

- `public/`：HTML、CSS、JavaScript、PWA 清单与图标。
- `serve.py`：本地 HTTPS 服务与 iPhone 安装引导。
- `使用说明.md`：完整使用方法与版本说明。

保持原 IP 与端口更新应用，以继续使用同一来源中的本地账单。请定期在设置中导出备份；GitHub 仓库保存的是程序代码，不包含手机上的账单。
