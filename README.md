# 小布的记账本 3.6

本地优先的 iPhone 记账 PWA，纯 HTML/CSS/JavaScript，账单保存在 `lanyu-ledger-v1`，没有账号或账单上传。

## 本版更新

- 余额表情只显示已有 PNG 静图，不加载、不缓存 GIF；保留两种金额规则和自定义分界。
- 总结支持按账月、按日、按起止日期范围，收入/支出/结余和分类统计同步。
- 分期还款支持多个平台，期数由用户填写，没有12期预设。每期可独立修改日期和金额，日期统一使用确认式日历。
- 选完月份、日期后不残留触摸焦点圈；键盘导航仍有焦点提示。
- 首页总余额下方显示本自然月计划还款额；19个弹窗固定大小，内部滚动。

## 分期还款

设置→预算与固定支出→分期还款计划。填写平台名、默认每期金额、首次日期和期数（1–600），再逐期调整。默认日期按月生成，29–31号在短月按月末处理；手动改过的日期或金额不会被默认值覆盖。

保存按钮为“保存并自动记账”。保存前会显示当前需补记的笔数和金额；已到期且未处理的期数会生成支出并扣减账本余额。每期用独立ID去重，同月、同日的多期互不冲突。已经记账的期数在计划编辑器中锁定；历史账单仍可在记录页正常编辑。

应用运行时每分钟、回到前台及打开时会检查。PWA关闭期间不能保证后台准时执行，下次打开时补记到期记录；这不是银行或支付软件实际代扣。暂停期间不记账，继续后会补记未处理的到期项。删除计划保留已有账单；删除自动账单后不会反复自动创建同一期。

所有计划与已处理ID随v1 JSON备份保留，旧备份无该字段时为空。

## 日期总结

打开月总结，切换“按月／按日／日期范围”。日期确认前不生效，取消保留原值；区间包含首尾两天。按日或范围的分类统计使用相同范围。账月起始日仍可设置1–28号，默认5号；分期日期按实际日历日，不随账月起始日移动。

## 原有功能

预算与分类预算、金额/日期/关键词筛选、常用筛选、年度总览、账单日历、目标、借出借入、固定支出模板、CSV、照片图标、备份提醒和PIN保留。分类和日期采用统一选择窗口，主页分类左右滑动，首页无需上下滑动。

## 启动

```sh
python -m pip install -r requirements.txt
python serve.py
```

Windows可双击启动局域网.cmd。沿用原IP/端口和已信任的证书，避免更换来源影响本机数据。`.local/`证书私钥不提交或打包。

离线缓存 `lanyu-shell-v33`，共59项（含4个余额PNG，不含GIF和emoji-pack.zip）。联网打开原应用，关闭重开至3.6，在设置→离线运行中确认59/59与本机读取检查通过，再飞行模式重开验证。

```sh
node tests/batch2.cjs
node tests/batch3.cjs
node tests/batch5.cjs
node tests/batch6.cjs
node tests/integration3.cjs
node tests/ui33.cjs
node tests/pickers34.cjs
node tests/app36.cjs
```

新验收覆盖静图与缓存、三种总结、日期取消/确认、多平台自定义分期、逐期日期/金额、自动记账、防重复、同日多期、暂停、已记期数保护、JSON实际恢复和离线补记；320×568、375×667、390×844通过单屏检查。测试用独立浏览器与模拟账单，iPhone Safari真机和真实系统后台生命周期仍需复测。
